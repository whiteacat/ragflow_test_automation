# 指标口径优化方案（降低漏判 / 误判）

> 目标：修掉「正确被判错」和「错误被判对」两类误差。
> 结论：**不是整体过严，而是严在了错的位置** —— 格式与语义层过严（缺归一化、字面匹配、二值评分），证据层过松（文档级即命中、全文任意共现、算不出来就免检）。

---

## 一、三条结论先行

1. **不建议下调验收阈值**。`GEN-02 ≥0.95`、`GEN-09 =1.00`、`GEN-05 ≥0.98` 是业务目标，不是量尺刻度。分数低应先怀疑量尺，而不是改分数线——否则只是把漏判藏起来。
2. **要修的是三类量尺**：① 文本归一化不统一；② 「字面全等」替代了「语义等价」；③ 判定不出来的题被静默排除（`None` 不进分母），导致分母缩水、指标虚高。
3. **有 3 个点会直接造成安全事故级误判**，优先级最高：
   - `forbidden_hit` 把「严禁使用 5.7MPa」这种**正确警示**判成违规 → 触发一票否决；
   - `is_abstention` 把「测量**不确定**度」判成拒答 → 可答题记 0；
   - `evidence_cover` 两侧归一化不一致（`18.84 MPa` vs `18.84MPa`）→ 证据召回被系统性低估。

## 三、优化原则

1. **修量尺，不改分数线**：阈值调整必须附校准集证据，不因"不好看"下调。
2. **三态输出**：每个规则指标同时给 `strict`（现行逻辑）、`relaxed`（新逻辑）、`uncertain`（进复核队列）。报告并列展示，差值 >5pp 标「口径敏感」。
3. **邻近性 > 全局共现**：标签与数值必须在同一窗口内共现，防关键词堆砌骗分。
4. **否定先于命中**：先判语境极性，再判是否命中。安全类（forbidden）必须走这条。
5. **放宽必须过 precision 门槛**：任何"变宽松"的改动，先证明不会把错的判成对。
6. **排除率透明**：每个指标必须输出 `n` / `n_excluded`，排除率 >10% 时该指标标记「不可信」。

## 四、改造方案

### 4.1 统一归一化层（新增 `src/textnorm.py`）

两侧共用一套，替换 `metrics_retrieval._norm` 与 `metrics_generation.normalize_text` 的分裂实现：

```python
CANON_UNITS = {  # 全部换算到基准单位，比较前先转
    "mpa": ("pressure", 1.0), "kpa": ("pressure", 0.001),
    "pa": ("pressure", 1e-6), "bar": ("pressure", 0.1),
    "kgf/cm2": ("pressure", 0.0980665), "kg/cm2": ("pressure", 0.0980665),
    "mw": ("power", 1.0), "kw": ("power", 0.001),
    "mm": ("length", 1.0), "t/h": ("flow", 1.0),
    "℃": ("temp", 1.0), "度": ("temp", 1.0), "%": ("pct", 1.0),
}

def normalize(s: str) -> str:
    s = unicodedata.normalize("NFKC", s or "")   # 全角→半角
    s = re.sub(r"[\u200b\u00a0]", "", s)          # 零宽/不换行空格
    s = re.sub(r"[*_`#>]", "", s)
    s = CN_NUM.sub(lambda m: str(cn2num(m.group())), s)  # 十八点八四→18.84
    s = re.sub(r"(\d)[,，](\d{3})", r"\1\2", s)   # 千分位
    s = s.replace("|", "\x01").replace("｜", "\x01")
    s = s.lower()
    for cn, en in UNIT_ALIASES: s = s.replace(cn, en)
    s = s.replace("～", "~").replace("—", "-").replace("至", "~").replace("到", "~")
    s = re.sub(r"\s+", "", s)
    s = re.sub(r"[的是为]", "", s)
    return s
```

配套：`canon_value(num, unit) -> (dim, value)`，用于跨单位比较。

**改动点**：`metrics_retrieval.py` 的 `_norm` 全部替换为 `textnorm.normalize`；`evidence_cover` 两侧都归一化。

### 4.2 数值匹配：完全一致 + 单位换算 + 区间

数值**不允许任何误差**：不做舍入、不做相对容差。`18.84` 与 `18.8` 视为不同值；
`18.84` 与 `18.840` 视为同一值（十进制数值相等）。

```python
def num_matches(fact: Num, answer: Num) -> bool:
    cf, ca = canon(fact), canon(answer)          # 同量纲换算到基准单位
    if cf and ca:
        return cf[0] == ca[0] and cf[1] == ca[1] # Decimal 精确相等
    return fact.value == answer.value            # 无单位时直接比十进制值
```

实现用 `decimal.Decimal` 解析原文，避免二进制浮点误差（`0.6*1e6 != 600*1000`）。

| 场景 | 处理 |
|---|---|
| `18.84` vs `18.8` | **不命中**（数值不同） |
| `18.84` vs `18.840` | 命中（十进制同值） |
| `0.6MPa` vs `600kPa` | 换算到 Pa 后精确相等 → 命中 |
| `1kW` vs `1000W` | 换算到 W 后精确相等 → 命中 |
| `0.6kgf/cm²` vs `0.0588399MPa` | 均为 58839.9 Pa → 命中 |
| `18.84` vs `23.55` | 不命中 |
| `18.84~23.55MPa` | 答案须**精确等于某个端点** → 命中；`20MPa`（中间值）与 `30MPa`（区间外）均不命中 |
| `≥18.84` / `不低于18.84` | 提取数值本身，比较符不参与匹配 |

> 决策记录：①最初方案采用「末位精度容差」，经确认改为**数值完全一致**，不接受 18.84 被 18.8 覆盖；
> ②单位换算保留（换算后精确相等才算命中）；③`18.84` 与 `18.840` 视为同值；④区间只认端点，中间值不覆盖。

### 4.3 标签同义 + 邻近窗口

1. **同义词表** `config/synonyms.yaml`（可热加载）：

```yaml
水压试验: [水压强度试验, 打压试验, 水压严密性试验]
省煤器: [economizer, 尾部受热面]
过热器: [过热段, 过热器管组]
给水泵: [给水前置泵, 主给水泵]
```

2. **匹配顺序**：原词 → 同义词闭包 → 核心词共现（如 `水压`+`试验` 同时出现）。
3. **邻近窗口**（关键防虚高）：标签与数值必须在 **40 字窗口**内共现，取二者位置差的最小值。

```python
def labels_near(labels, nums, answer, window=40) -> bool:
    positions = [pos_of(l) for l in labels] + [pos_of(n) for n in nums]
    if any(p < 0 for p in positions): return False
    return max(positions) - min(positions) <= window
```

4. **分档**（替换现在的 0/1）：

| 判定 | 分值 |
|---|---|
| 数值 + 标签在窗口内共现 | 1.0 |
| 标签命中，数值缺失 | 0.5（且计入 `uncertain`） |
| 仅同义词近似命中（核心词共现） | 0.8 |
| 都不满足 | 0 |

`GEN-02` 同时输出 `fact_recall_strict`（现行二值）与 `fact_recall_relaxed`（分档加权）。

### 4.4 否定语境（安全优先）

```python
NEG_SAFE = ["严禁", "禁止", "不得", "切勿", "避免", "绝不能"]
NEG_FACT = ["不适用", "未使用", "不使用", "并非", "不属于", "没有采用"]
NEG_MARK = ["不", "未", "无", "非", "禁"]

def polarity(answer, hit_pos, span=15) -> str:
    win = answer[max(0, hit_pos-span): hit_pos+len(hit)+span]
    if any(k in win for k in NEG_SAFE): return "warn"     # 安全警示
    if any(k in win for k in NEG_FACT): return "deny"     # 否定事实
    if any(k in win for k in NEG_MARK): return "weak_neg"
    return "affirm"
```

| 指标 | `affirm` | `deny` | `warn` | `weak_neg` |
|---|---|---|---|---|
| `forbidden_hit` | 1（违规） | 0（未违规） | **0（正确警示）** | 进 `uncertain`，不自动否决 |
| `fact_covered` | 命中 | **不命中** | 命中 | 命中但标 `negated` |

> `warn` 不算违规是本次最重要的口径修正：「严禁执行 5.7MPa」是正确答案，不是安全事故。

### 4.5 拒答三态

1. **先排除误伤词**：`不确定(度|性|因素|区间|分析)`、`无法确定(因素)` 走白名单，不判拒答。
2. **扩充词表**：`资料中未提及`、`未提及`、`暂无相关`、`无法提供`、`超出知识范围`、`建议联系`、`需咨询`、`no information`、`not mentioned`、`cannot provide`。
3. **位置加权**：拒答语出现在答案前 20% 且答案 <200 字 → `yes`；出现在中后段或伴随大量实质内容 → `uncertain`。
4. **三态输出**：`abstained ∈ {0, 1, None}`；`None` 表示「疑似拒答」，进 `review_queue`，**不直接扣分**。

```python
def abstention_state(answer) -> Optional[int]:
    a = normalize(answer)
    if MISFIRE_RE.search(a): return 0          # 不确定度等
    if not a: return None
    head, ratio = a[:int(len(a)*0.2)], len(a)
    if any(p in a[:60] for p in ABSTAIN_PATTERNS_EXT):
        return 1 if ratio < 200 else None
    return 0
```

### 4.6 引用识别

**新增模式**（避免把列表序号当引用）：

| 模式 | 约束 |
|---|---|
| `[1]` `[1,2]` `[^1]` | 必须出现在答案**末尾 200 字**内，且编号 ≤ 检索 chunk 数 |
| `（1）` `(1)` | 同上 |
| `《…》` + `第X条` / `4.2条` | 无条件 |
| 裸文件名 `*.pdf|docx|xlsx` | 无条件 |
| `依据|根据|见|详见` + 文档名/条款 | 无条件 |

**新增准确性档位**：`citation_complete` 仍只看「有没有」，新增 `citation_grounded`（引用目标是否在本次检索 chunk 中）用于区分「引用完整」与「引用真实」。

### 4.7 检索侧

1. `_norm` 换 `textnorm.normalize`（R1、R2 一起修）。
2. 分句覆盖：**精确包含** 或 **字二元组召回 ≥0.85** 任一成立即算覆盖；同时输出 `evidence_recall_exact` / `evidence_recall_fuzzy`。
3. `hit_at_k` 文档级命中降级：文档级只能算「候选命中」，需在报告里单列 `doc_only_hits`；`RAG-01/02/03` 主口径仍要求 chunk 级命中，文档级只用于「未映射题」的参考值（R3）。
4. `cross_doc_coverage` 纳入 `acceptable_chunks`（R4）。

### 4.8 分档评分与排除率

1. `order_correct`：事实重复提及时取**最早出现的连续段**；若某事实只有标签命中、无数值命中，用标签位置代替，而不是直接 `None`（O1、O2）。
2. 全部规则指标在 `per_question` 增加：

```json
{"fact_recall_strict": 0.67, "fact_recall_relaxed": 0.83,
 "uncertain": ["水压试验(标签命中/数值缺失)"],
 "excluded_reason": null}
```

3. `report` 每个指标输出 `n` / `n_excluded` / `exclude_rate`；`exclude_rate > 0.10` 时该指标打 ⚠️（T2）。

### 5.2 评估指标与准入门槛

|---|---|---|
| `fact_covered` | recall（不漏判） | ≥0.95 |

### 5.3 回归方式

- 校准集固化为 `tests/test_scoring_calibration.py`，参数化用例，`pytest` 一条命令跑完；

- 现有 61 条测试必须在改造后仍全绿（口径变更需同步更新受影响的断言，不允许删除）。

### 5.4 A/B 对比

同一批 `per_question.jsonl` 分别用 `strict` / `relaxed` 重算：

- 差值 ≤3pp：冻结新口径；
- 3~5pp：逐条抽样解释；
- \>5pp：说明有系统性错判未定位，禁止上线。

## 七、风险与回滚

| 风险 | 表现 | 对策 |
|---|---|---|
| 放宽后指标虚高 | relaxed 比 strict 高 10pp+ | 邻近窗口 + precision 门槛 + 每批抽检 20 条 |
| 关键词堆砌绕过 | 答案罗列术语即覆盖 | 窗口共现 + 数值必须匹配 + 标签最多 0.5 分 |
| 否定规则误杀真违规 | 「不得低于18.84」是要求，不是否定 | 只对 `warn/deny` 白名单降级；`weak_neg` 进复核不自动判 |
